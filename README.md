# Oakley Physio

Marketing website for Oakley Physio — North Manchester's No.1 physiotherapy practice in Prestwich, Manchester.

## Tech stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS (orange / charcoal / white brand theme)
- Framer Motion (scroll-triggered animations)
- next/image

## Pages

- Home
- Services (Musculo-Skeletal, Pilates, Continence, Acupuncture, Pregnancy, Elderly Rehab, Women's Health)
- The Team
- Appointments
- Clients
- Contact Us

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the site.

## Build

```bash
npm run build
npm run start
```
